# parserm-rs

Быстрый разбор выходов RepeatMasker (`.out`, `.align`): доли генома по классам и семействам повторов, возраст, ландшафт дивергенции.

Это порт на Rust скрипта `parseRM.pl` из проекта [Parsing-RepeatMasker-Outputs](https://github.com/4ureliek/Parsing-RepeatMasker-Outputs) (Kapusta, Suh & Feschotte). Те же опции и те же файлы на выходе, **примерно в 900 раз быстрее**. Портированы режимы `-p`, `-a`, `-l`.

## Скорость

Файл `bench.out`: 300 004 повтора, около 24 млн нуклеотидов. Опции `-p -a 5,15 -l 50,1`, Mac (arm64), `hyperfine`.

| | `parseRM.pl` | `parserm-rs` | Выигрыш |
|---|---|---|---|
| Время | 304,7 с | 0,33 с | в 900 раз |
| Память | 2088 МБ | 120 МБ | в 17 раз |

На входе в 54 млн нуклеотидов Perl работал 725 с и занял 4,3 ГБ. Результаты Rust совпали.

Файл синтетический.

## Установка

Нужен [Rust](https://rustup.rs).

```sh
git clone https://github.com/neon-straw/parserm-rs
cd parserm-rs
cargo install --path .
parserm-rs -h
```

Без установки: `cargo build --release`, бинарник будет в `target/release/parserm-rs`.

## Быстрый старт

Скачать аннотацию дрозофилы с UCSC (3,8 МБ) и построить сводку, ландшафт и возрастные категории:

```sh
curl -O https://hgdownload.soe.ucsc.edu/goldenPath/dm6/bigZips/dm6.fa.out.gz
gunzip dm6.fa.out.gz

parserm-rs -i dm6.fa.out -p -a 5,15 -l 50,1 -k -v
```

Файлы пишутся рядом со входным:

| Файл | Что внутри |
|---|---|
| `*.parseRM.summary.tab` | сводка по классам и семействам |
| `*.parseRM.all-repeats.tab` | числа по каждому повтору |
| `*.landscape.Div.{Rname,Rfam,Rclass}.tab` | ДНК по интервалам дивергенции, для графиков |
| `*.splitage.tab` | молодые, древние и промежуточные повторы |

## Примеры

```sh
# только сводка, с процентами от генома (-g: длина генома в нуклеотидах)
parserm-rs -i dm6.fa.out -p -g 142573017

# ландшафт: интервалы по 1% до 50%
parserm-rs -i dm6.fa.out -l 50,1

# возраст в млн лет: скорость замен 0.0021, граница 25 My
parserm-rs -i dm6.fa.align -a 25 -m 0.0021

# только ДНК-транспозоны
parserm-rs -i dm6.fa.out -p -w class,DNA

# все .out и .align из папки
parserm-rs -i my_genomes/ -d -p -l 50,1
```

## Опции

| Опция | Что делает |
|---|---|
| `-i` | входной `.out` или `.align` (с `-d`: папка) |
| `-p` | сводка по повторам, семействам, классам |
| `-l <max>,<bin>` | ландшафт дивергенции |
| `-a <X>`, `<X,Y>` или файл | разделение по возрасту |
| `-m <скорость>` | считать в My, а не в % дивергенции |
| `-g <длина>` | длина генома для процентов |
| `-k` | поправка Jukes–Cantor (для `.out`) |
| `-w <тип,имя>`, `-c` | взять часть повторов; `-c`: по вхождению |
| `-s all`, `-s nonTE` | оставить не-TE повторы |
| `-r lib.fa` | добавить длины консенсусов |
| `-e file` | поправки классов и семейств |
| `--fix-quirks` | исправить баги оригинала (результат отличается от Perl) |

Полный список: `parserm-rs -h`. Опций `-f` и `-n` нет: им нужен BioPerl.

## Совместимость с Perl

Выходные файлы `parserm-rs` сверены с `parseRM.pl` на тестовом корпусе: 25 входных файлов, 21 набор опций, 525 запусков, расхождений нет.

На реальном выходе RepeatMasker для дрозофилы (UCSC `dm6.fa.out`, 137558 строк, флаги `-p -g 143726002 -a 5,15 -l 50,1 -k -v`) расхождений тоже нет. Perl считал 506 с при пике 6,3 ГиБ, Rust — 0,10 с при пике 23 МиБ. В сыром diff отличаются только абсолютные пути к двум копиям входа.

- Все поля совпадают точно, кроме колонок средних. Для них допустимо относительное отличие до 1e-9, так как порядок суммирования другой.
- Порядок строк в выходных файлах может отличаться, потому что Perl выводит ключи хэша в случайном порядке.
- Баги оригинала воспроизведены намеренно. Их список и принятые отклонения: [COMPATIBILITY.md](COMPATIBILITY.md).

Тесты: `cargo test`. Среди них проверка на готовых результатах оригинала: в `tests/golden` лежат файлы, которые выдал `parseRM.pl` на входах из `tests/corpus`, и `parserm-rs` должен выдать такие же.

## Как это ускорено

Perl перебирает каждый нуклеотид каждого повтора. Rust делит каждую последовательность генома (хромосому или контиг) на отрезки по границам повторов и считает отрезок целиком. Время зависит от числа повторов, а не от числа замаскированных нуклеотидов. Подробности: [COMPATIBILITY.md](COMPATIBILITY.md).
